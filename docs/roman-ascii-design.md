# FORVM: Roman ASCII direction

Date: 2026-10-27. Local iteration only, no deployment.

## Intent
Keep the existing reading order and section layout. Restyle Seros as an ancient Roman information terminal with contemporary, precise controls. Ancient retro means inscriptions, arched sculpture, bronze characters and warm stone, not novelty fonts or unreadable body text. Apple-like polish is interpreted as responsive feedback, soft control corners, deliberate spacing and restrained physical motion, not copied branding.

## Visual system
- Warm paper #f6f3eb, charcoal olive #171914, bronze accent #65502f, illuminated brass #d7bc85.
- Existing local Source Serif for monumental headings, system sans for readable prose, monospace for inscriptions and ASCII.
- Existing engraving converted once in the browser to a 100 by 40 character sculpture. Original image remains the no-JavaScript or failed-canvas fallback.
- Slow sculpture breath and orbital motion only inside the visible hero. Pause/resume is explicit, hidden tabs pause, reduced-motion disables animation. No moving copy, scroll hijack, cursor replacement, or flashing effects.
- Shared styling carries through marketing, toolkit and generated policy documents. Policy wording is not manually changed.

## Business features
A separate /tools destination keeps the main layout intact. Local-only service-fit guidance, workflow reference patterns, project brief generation/copy/download and an illustrative time-capacity calculator. These help communicate business needs, not simulate a client system. Existing approval demo is not expanded. No new demo, remote storage, analytics, account, invented price, or ROI promise.

## Acceptance
Real Chromium checks for responsive layout, accessibility scans, existing keyboard paths, pause/resume and reduced motion, useful-tool calculations and input validation, safe handling of user text, local copy/download and no remote submissions. Keep the preview at localhost:8081. Conversion and subjective preference require user review and are not automated-test claims.
